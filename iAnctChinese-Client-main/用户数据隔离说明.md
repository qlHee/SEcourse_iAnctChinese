# 用户数据隔离说明

## 🎯 功能说明

现在系统已经实现了**完整的用户数据隔离**：
- ✅ 每个用户只能看到自己创建的项目
- ✅ 每个用户只能看到自己创建的文档
- ✅ 用户之间的数据完全独立，互不干扰
- ✅ 登出后重新登录，数据依然存在

---

## 🔒 工作原理

### 数据关联
每个项目和文档都会自动关联创建者的用户ID：

```javascript
// 项目结构
{
  id: "project-uuid",
  userId: 1,              // 👈 关联用户ID
  name: "我的项目",
  description: "...",
  createdAt: "2025-10-15"
}

// 文档结构
{
  id: "doc-uuid",
  userId: 1,              // 👈 关联用户ID
  projectId: "project-uuid",
  name: "文档1",
  content: "...",
  entityAnnotations: [...]
}
```

### 数据过滤
- **加载时**：只加载当前登录用户的数据
- **保存时**：保留其他用户的数据，只更新当前用户的数据
- **创建时**：自动添加当前用户的ID

## 🛡️ 安全机制

### 1. 登录检查
创建项目或文档时会检查是否登录：
```javascript
if (!userId) {
    console.error('No user logged in');
    return null;
}
```

### 2. 数据隔离
```javascript
// 只加载当前用户的项目
const userId = getCurrentUserId();
return allProjects.filter(p => p.userId === userId);
```

### 3. 数据保护
保存时不会覆盖其他用户的数据：
```javascript
// 保留其他用户的项目
const otherProjects = allProjects.filter(p => p.userId !== userId);
// 只更新当前用户的项目
const merged = [...otherProjects, ...this.projects];
```

## 🔄 数据迁移

### 旧数据处理
如果你之前创建的项目/文档没有`userId`字段：
1. 第一个登录的用户会"继承"这些数据
2. 或者手动给旧数据添加`userId`字段

### 手动迁移（可选）
打开浏览器控制台（F12）：
```javascript
// 查看当前所有项目
console.log(JSON.parse(localStorage.getItem('appdata_projects_v1')));

// 给旧项目添加userId（假设分配给用户1）
const projects = JSON.parse(localStorage.getItem('appdata_projects_v1'));
const updated = projects.map(p => ({ ...p, userId: p.userId || 1 }));
localStorage.setItem('appdata_projects_v1', JSON.stringify(updated));

// 文档同理
const docs = JSON.parse(localStorage.getItem('appdata_documents_v1'));
const updatedDocs = docs.map(d => ({ ...d, userId: d.userId || 1 }));
localStorage.setItem('appdata_documents_v1', JSON.stringify(updatedDocs));
```

## 🐛 常见问题

### Q: 登录后看不到之前的项目？
**A**: 之前的项目没有关联用户ID。有两个解决方案：
1. 重新创建项目（推荐新用户）
2. 手动迁移数据（见上面的迁移脚本）

### Q: 切换用户后数据丢失了？
**A**: 数据没有丢失，只是被过滤了。重新登录原来的账号就能看到。

### Q: 想给其他用户分享我的项目？
**A**: 目前不支持共享功能。每个用户的数据完全独立。如需共享：
1. 导出数据（功能待实现）
2. 或手动复制文档内容

### Q: 可以查看所有用户的数据吗？
**A**: 只有管理员可以（需要单独实现管理功能）。普通用户只能看到自己的数据。
