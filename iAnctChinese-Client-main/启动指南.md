# iAnctChinese 启动指南

## 📦 准备工作

### 1. 安装 Node.js
确保已安装 Node.js（建议 v16 或更高版本）
- 下载地址: https://nodejs.org/

### 2. 安装 Python
确保已安装 Python 3.8+（用于大模型服务）
- 下载地址: https://www.python.org/

## 🚀 快速启动（三步）

### 第一步：安装 Express 后端依赖
```bash
# 进入 server 目录
cd server

# 安装依赖
npm install
```

**PyCharm 用户提示**: 可以在 PyCharm 的终端中运行上述命令

### 第二步：启动 Qwen 大模型服务

**选项 A - 使用命令行:**
```bash
# 新开一个终端窗口
cd qwen-project-main/qwen-project-main

# 安装 Python 依赖（首次运行）
pip install -r requirements.txt

# 启动服务
python qwen.py
```

**选项 B - 使用 PyCharm:**
1. 在 PyCharm 中打开 `qwen-project-main/qwen-project-main/qwen.py`
2. 确保项目解释器已配置（PyCharm 会自动提示安装依赖）
3. 或在 PyCharm 底部「Python Packages」中搜索并安装：
   - torch
   - transformers
   - flask
   - flask-cors
4. 点击右键 → Run 'qwen'

⚠️ **注意**: qwen.py 中的 `model_path` 需要指向你本地的模型路径

### 第三步：启动 Express 服务器
```bash
# 在 server 目录
npm start
```

或使用开发模式（自动重启）：
```bash
npm run dev
```

## 🌐 访问应用

启动成功后，打开浏览器访问：
- **前端地址**: http://localhost:3000
- **API 地址**: http://localhost:3000/api

## 📋 功能说明

### ✅ 已集成功能
1. **实体标注** - 手动选择文本进行标注
2. **古文解析** - 使用大模型解析古汉语（需要 qwen.py 运行）
3. **自动分词** - 使用 nodejieba 进行中文分词（无需额外服务）

### 🔧 服务架构
```
前端 (http://localhost:3000)
  ↓
Express 服务器 (端口 3000)
  ├── 静态文件服务
  ├── 自动分词 (nodejieba)
  └── 古文解析 → 转发到 Qwen 服务 (端口 5000)
```

## ⚙️ 端口说明
- **3000** - Express 主服务器（前端 + API）
- **5000** - Python Qwen 大模型服务（仅供 Express 内部调用）

## 🛠️ 故障排查

### 问题 1: npm install 失败
**解决方案:**
```bash
# 切换到国内镜像源
npm config set registry https://registry.npmmirror.com
npm install
```

### 问题 2: nodejieba 安装失败（Windows）
**解决方案:**
1. 安装 Visual Studio Build Tools
2. 或使用预编译版本: `npm install nodejieba --ignore-scripts`

### 问题 3: 古文解析失败
**检查清单:**
- [ ] qwen.py 是否正在运行？
- [ ] 端口 5000 是否被占用？
- [ ] model_path 路径是否正确？
- [ ] 模型文件是否完整？

### 问题 4: 前端空白页
**解决方案:**
- 检查浏览器控制台是否有错误
- 确认 Express 服务器已启动
- 尝试清除浏览器缓存

## 📝 开发提示

### 修改 API 地址
如果需要修改后端地址，在浏览器控制台设置：
```javascript
window.IANCT_API_BASE = 'http://your-server:port';
```

### 修改 Express 端口
在 `server/index.js` 顶部或使用环境变量：
```bash
PORT=8080 npm start
```

### 修改 Qwen 服务地址
使用环境变量：
```bash
QWEN_SERVICE=http://localhost:5000 npm start
```

## 📦 生产部署建议

1. **前端打包**: 考虑使用构建工具优化前端资源
2. **进程管理**: 使用 PM2 管理 Node.js 进程
3. **反向代理**: 使用 Nginx 作为反向代理
4. **HTTPS**: 配置 SSL 证书

## 🤝 技术栈
- **前端**: HTML5, CSS3, Vanilla JavaScript
- **后端**: Express.js (Node.js)
- **分词**: nodejieba
- **大模型**: Python + Transformers + Qwen
- **数据存储**: localStorage (浏览器本地)
