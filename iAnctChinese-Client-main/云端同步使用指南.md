# 云端同步功能使用指南

## 🎉 功能介绍

现在你的系统支持**云端数据同步**了！这意味着：

✅ **换电脑登录，能看到所有数据**  
✅ **数据永久保存在服务器**  
✅ **多设备实时同步**  
✅ **不会因清除浏览器缓存而丢失**

---

## 🚀 快速开始

### 第1步：启动后端服务

```bash
cd server
npm start
```

看到这个提示就成功了：
```
🚀 用户管理服务已启动 (Express)
📡 端口: 5002
📁 数据文件: data/data.json
✅ 功能: 用户注册、登录、信息更新、项目管理、文档管理
✅ 数据: 自动保存到 data.json
```

### 第2步：打开前端

浏览器打开 `index.html`

### 第3步：登录账号

使用你的账号登录，数据会自动从云端加载！

## 🔄 数据同步说明

### 自动同步的操作

以下操作会自动同步到服务器：

| 操作 | 同步到云端 | 说明 |
|------|-----------|------|
| 创建项目 | ✅ | 立即保存到 data.json |
| 编辑项目 | ✅ | 实时更新 |
| 删除项目 | ✅ | 同时删除相关文档 |
| 创建文档 | ✅ | 立即保存 |
| 编辑文档 | ✅ | 自动保存（1秒后）|
| 删除文档 | ✅ | 立即删除 |
| 导入文档 | ✅ | 批量上传 |
| 实体标注 | ✅ | 随文档保存 |

### 数据流程图

```
用户操作
  ↓
前端 (data-manager.js)
  ↓
HTTP 请求
  ↓
后端 API (user-server.js)
  ↓
保存到 data/data.json
```

## 🔒 用户数据隔离

### 后端自动过滤

所有API都会按用户ID过滤数据：

```javascript
// 获取项目时
GET /api/projects?userId=1  → 只返回用户1的项目

// 获取文档时
GET /api/documents?userId=1  → 只返回用户1的文档
```

### 安全机制

- ✅ 用户只能看到自己的数据
- ✅ 用户只能修改自己的数据
- ✅ 删除项目会同时删除相关文档
- ✅ 所有操作都需要用户ID验证

## 🌐 API 接口文档

### 项目管理

#### 获取用户的所有项目
```http
GET /api/projects?userId=1
```

#### 创建项目
```http
POST /api/projects
Content-Type: application/json

{
  "userId": 1,
  "name": "项目名",
  "description": "项目描述"
}
```

#### 更新项目
```http
PUT /api/projects/:projectId
Content-Type: application/json

{
  "name": "新项目名",
  "description": "新描述"
}
```

#### 删除项目
```http
DELETE /api/projects/:projectId
```

### 文档管理

#### 获取用户的所有文档
```http
GET /api/documents?userId=1&projectId=xxx
```

#### 创建文档
```http
POST /api/documents
Content-Type: application/json

{
  "userId": 1,
  "projectId": "xxx",
  "name": "文档名",
  "content": "文档内容",
  "author": "作者"
}
```

#### 更新文档
```http
PUT /api/documents/:documentId
Content-Type: application/json

{
  "content": "新内容",
  "entityAnnotations": [...]
}
```

#### 删除文档
```http
DELETE /api/documents/:documentId
```

## ⚙️ 配置选项

### 云端同步开关

默认情况下，云端同步是**启用**的。

#### 查看状态

打开浏览器控制台（F12）：
```javascript
console.log(dataManager.cloudSyncEnabled);  // true = 已启用
```

#### 临时关闭云端同步

```javascript
dataManager.cloudSyncEnabled = false;
localStorage.setItem('cloudSyncEnabled', 'false');
```

#### 重新启用

```javascript
dataManager.cloudSyncEnabled = true;
localStorage.setItem('cloudSyncEnabled', 'true');
location.reload();
```

### 修改API地址

如果服务器在其他地址，可以修改：

```javascript
// 在浏览器控制台或 index.html 中设置
window.USER_API_BASE = 'http://your-server:5002';
```

## 🔄 切换电脑使用

### 电脑A（首次使用）
1. 启动服务器：`cd server && npm start`
2. 登录账号
3. 创建项目和文档
4. 数据自动保存到 `data/data.json`

### 电脑B（新电脑）
1. 复制整个项目文件夹到电脑B
2. 启动服务器：`cd server && npm start`
3. 登录**相同的账号**
4. ✅ 能看到所有数据！

### 关键点

- **data/data.json 文件必须复制到新电脑**
- 或者使用网络共享存储（如NAS、云盘）
- 或者部署到真正的云服务器

## 🐛 故障排除

### 问题1：数据没有同步

**检查：**
```bash
# 1. 确认服务器正在运行
curl http://localhost:5002/api/health

# 2. 查看浏览器控制台是否有错误
按 F12 → Console 标签

# 3. 检查云端同步是否启用
console.log(dataManager.cloudSyncEnabled);
```

**解决：**
- 确保 `npm start` 正在运行
- 检查端口5002没有被占用
- 清除浏览器缓存后重试

### 问题2：创建项目/文档失败

**可能原因：**
- 服务器未启动
- 网络连接失败
- 用户未登录

**解决：**
```bash
# 重启服务器
cd server
npm start

# 检查登录状态
console.log(authManager.getCurrentUser());
```

### 问题3：数据保存到本地而不是云端

**原因：** 云端同步被关闭或服务器连接失败

**解决：**
```javascript
// 启用云端同步
dataManager.cloudSyncEnabled = true;
localStorage.setItem('cloudSyncEnabled', 'true');
location.reload();
```

### 问题4：换电脑后看不到数据

**原因：** data.json 文件没有复制到新电脑

**解决：**
1. 从旧电脑复制 `data/data.json` 文件
2. 粘贴到新电脑的 `data/data.json`
3. 重启服务器
4. 重新登录

## 📊 性能优化

### 自动保存间隔

文档编辑时，默认1秒后自动保存。可以修改：

```javascript
// 在 ui-manager.js 中修改
this.autoSaveTimer = setTimeout(() => {
    dataManager.saveEditingDocument();
    this.showSaveStatus();
}, 2000);  // 改为2秒
```

### 批量操作

导入多个文档时，系统会批量上传到服务器，无需等待。
