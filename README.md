# iAnctChinese - 汉语智能标注平台

古文智能标注与解析平台，为古汉语文本研究提供实体标注、智能解析、自动分词和答疑等功能。

## 项目简介

本项目是一个基于 Web 的古文智能处理系统，支持用户对古汉语文本进行多维度的分析和标注。系统提供项目化管理，用户可创建项目、导入文档，并使用 AI 辅助工具进行古文研究。

## 核心功能

- **古文解析**：基于 AI 的古文智能解析，辅助理解文意
- **古文答疑**：针对文本内容的智能问答功能
- **自动分词**：对古文进行自动分词，方便实体标注
- **实体标注**：对古文中的人物、地名、时间、器物、概念等实体进行手动标注
- **数据导出**：导出标注结果和文档内容
- **数据管理**：不同用户数据分离，支持多项目、多文档的组织管理


## 技术架构

### 前端 (client)
- 纯静态 Web 应用
- 基于原生 JavaScript 开发
- 响应式界面设计

### 后端 (server)
分为三个独立服务：

1. **AI 服务** (端口 5004)
   - 技术栈：Python + Flask
   - 功能：古文解析、古文答疑
   
2. **分词服务** (端口 5001)
   - 技术栈：Python + Flask + jieba
   - 功能：古文自动分词

3. **用户数据服务** (端口 5002)
   - 技术栈：Node.js + Express
   - 功能：用户管理、数据持久化

### 数据存储
- **database/**：系统数据存储目录，包含用户数据和项目数据
- **exported data/**：用户导出的标注文档存储目录
