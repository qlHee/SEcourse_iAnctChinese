# 项目说明文档

## 📝 项目概述

本项目为古文解析服务，基于大模型API实现古文的智能解析功能。

---

## ⚙️ 系统配置要求

### 1. 硬件配置
- ✅ **无需GPU**：使用云端大模型API，无需本地GPU
- ✅ **普通电脑即可**：内存 4GB+ 即可运行

### 2. 软件配置
- **Python**: 3.8+
- **相关依赖包**（详见requirements.txt）
  - flask
  - flask-cors
  - requests

---

## 🚀 使用教程

### 步骤1：安装依赖

```bash
cd qwen-project-main
pip install -r requirements.txt
```

### 步骤2：配置API密钥 ⚠️ 重要

打开 `qwen.py` 文件，在文件顶部的**配置区域**填写您的API配置：

#### 方式1：使用OpenAI API（推荐）

```python
API_TYPE = "openai"
API_KEY = "sk-xxxxxxxxxxxxx"  # ⚠️ 必填：填写您的OpenAI API Key
API_BASE_URL = "https://api.openai.com/v1"  # 官方地址
MODEL_NAME = "gpt-3.5-turbo"
```

**国内用户建议**：可以使用OpenAI兼容的国内API服务，只需修改 `API_BASE_URL` 即可。

#### 方式2：使用阿里云通义千问

```python
API_TYPE = "qwen"
API_KEY = "sk-xxxxxxxxxxxxx"  # ⚠️ 必填：填写通义千问API Key
API_BASE_URL = "https://dashscope.aliyuncs.com/api/v1/services/aigc/text-generation/generation"
MODEL_NAME = "qwen-turbo"
```

**获取方式**：
1. 访问 https://dashscope.aliyun.com/
2. 注册并开通通义千问服务
3. 在控制台获取API Key

#### 方式3：使用百度文心一言

```python
API_TYPE = "wenxin"
API_KEY = "xxxxxxxxxxxxx"  # ⚠️ 必填：百度API Key
SECRET_KEY = "xxxxxxxxxxxxx"  # ⚠️ 必填：百度Secret Key
MODEL_NAME = "ERNIE-Bot-turbo"
```

**获取方式**：
1. 访问 https://cloud.baidu.com/product/wenxinworkshop
2. 注册并创建应用
3. 获取API Key和Secret Key

#### 方式4：使用智谱AI (ChatGLM)

```python
API_TYPE = "chatglm"
API_KEY = "xxxxxxxxxxxxx"  # ⚠️ 必填：智谱AI API Key
API_BASE_URL = "https://open.bigmodel.cn/api/paas/v4/chat/completions"
MODEL_NAME = "glm-4"
```

**获取方式**：
1. 访问 https://open.bigmodel.cn/
2. 注册并创建API Key
3. 复制API Key

#### 方式5：使用Anthropic Claude

```python
API_TYPE = "claude"
API_KEY = "sk-ant-xxxxxxxxxxxxx"  # ⚠️ 必填：Claude API Key
API_BASE_URL = "https://api.anthropic.com/v1/messages"
MODEL_NAME = "claude-3-sonnet-20240229"
```

### 步骤3：启动服务

```bash
python qwen.py
```

看到以下信息表示启动成功：

```
============================================================
🚀 古文解析服务已启动 (基于大模型API)
============================================================

🤖 API类型: openai
📝 模型: gpt-3.5-turbo
🔗 接口: POST http://localhost:5000/api/analyze

```

### 步骤4：测试服务

打开浏览器访问前端页面，或使用curl测试：

```bash
curl -X POST http://localhost:5000/api/analyze \
  -H "Content-Type: application/json" \
  -d '{"text":"学而时习之，不亦说乎"}'
```

## 🐛 常见问题

### Q1: 如何获取API Key？

**A**: 请参考上面"步骤2：配置API密钥"部分，每种API都有详细的获取方式。

### Q2: 启动时提示"未配置API密钥"？

**A**: 请确保在 `qwen.py` 文件中填写了正确的API Key：
```python
API_KEY = "sk-xxxxxxxxxxxxx"  # 不要使用默认的 "YOUR_API_KEY_HERE"
```

### Q3: 调用API时报错"401 Unauthorized"？

**A**: API Key 不正确或已过期，请检查：
1. API Key 是否填写正确（没有多余空格）
2. API Key 是否已过期
3. 账户余额是否充足

### Q4: 调用API时很慢或超时？

**A**: 可能是网络问题，解决方案：
1. 国外API（OpenAI、Claude）：使用代理或国内中转服务
2. 增加超时时间：修改 `TIMEOUT = 120`
3. 使用国内API（通义千问、文心一言）

### Q5: 如何切换不同的大模型？

**A**: 修改 `qwen.py` 中的配置：
```python
# 修改 API_TYPE 和对应的配置
API_TYPE = "qwen"  # 改为你想用的API类型
API_KEY = "新的API Key"
MODEL_NAME = "对应的模型名称"
```

### Q6: 能否同时使用多个API？

**A**: 当前版本不支持，建议根据需要选择一个API。如需切换，只需修改配置并重启服务即可。

### Q7: API费用太高怎么办？

**A**: 几个建议：
1. 使用有免费额度的服务（文心一言、智谱AI）
2. 选择较便宜的模型（GPT-3.5、qwen-turbo）
3. 限制使用次数
4. 考虑回到本地部署方案
