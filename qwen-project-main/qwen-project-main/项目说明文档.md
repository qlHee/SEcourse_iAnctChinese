# 项目说明文档

## 项目概述

本项目是古汉语解析助手，使用大模型 API 提供古文解析功能。

**重要更新**：项目已从本地部署 Qwen3-0.6B 模型改为调用远程大模型 API，支持阿里通义千问和 DeepSeek。

## 系统要求

### 硬件配置

- ✅ 无特殊硬件要求（不再需要 GPU）
- ✅ 普通电脑即可运行

### 软件配置

- Python 3.8+
- 网络连接（用于调用 API）
- 相关依赖包（详见 requirements.txt）

## 使用教程

### 1. 下载项目

从 GitHub 或其他途径获取项目代码。

### 2. 安装依赖

```bash
cd qwen-project-main
pip install -r requirements.txt
```

### 3. 配置 API Key

**⚠️ 重要步骤：必须配置 API Key 才能使用**

#### 第一步：复制配置文件

```bash
cp config.example.json config.json
```

#### 第二步：获取 API Key

选择以下任一 API 提供商：

**选项 1：阿里通义千问 (推荐)**
1. 访问：https://dashscope.console.aliyun.com/
2. 注册并开通 DashScope 服务
3. 创建 API Key

**选项 2：DeepSeek**
1. 访问：https://platform.deepseek.com/
2. 注册账号
3. 创建 API Key

#### 第三步：填入 API Key

打开 `config.json` 文件，找到对应的配置项：

```json
{
  "api_provider": "qwen",
  "api_config": {
    "qwen": {
      "api_key": "在这里填入您的通义千问 API Key",
      "base_url": "https://dashscope.aliyuncs.com/compatible-mode/v1",
      "model": "qwen-turbo"
    },
    "deepseek": {
      "api_key": "在这里填入您的 DeepSeek API Key",
      "base_url": "https://api.deepseek.com",
      "model": "deepseek-chat"
    }
  }
}
```

**API Key 填写位置说明**：
- 如果使用通义千问：在 `"qwen"` -> `"api_key"` 处填入您的 API Key
- 如果使用 DeepSeek：在 `"deepseek"` -> `"api_key"` 处填入您的 API Key
- 修改 `"api_provider"` 字段选择使用哪个 API（`"qwen"` 或 `"deepseek"`）

### 4. 启动后端服务

```bash
python qwen.py
```

看到以下输出表示启动成功：

```
============================================================
古文解析 API 服务启动中...
API 提供商: qwen
使用模型: qwen-turbo
服务地址: http://0.0.0.0:5000
============================================================
```

### 5. 启动前端页面

打开 `web/index.html` 文件，在浏览器中访问。

### 6. 使用功能

1. 在"输入古文"框中输入想要解析的古文
2. 点击"解析"按钮
3. 等待解析结果显示在"解析结果"区域

## 注意事项

### 1. API Key 安全

- ⚠️ **切勿**将包含真实 API Key 的 `config.json` 文件提交到公开仓库
- API Key 泄露可能导致账户被盗刷
- 如不慎泄露，请立即在对应平台重置 API Key

### 2. 费用说明

- 调用大模型 API 会产生费用，请查看各平台的定价策略
- 建议设置费用上限，避免意外产生高额费用
- 通义千问定价：https://help.aliyun.com/zh/dashscope/developer-reference/tongyi-qianwen-metering-and-billing
- DeepSeek 定价：https://platform.deepseek.com/api-docs/pricing/

### 3. 网络要求

- 需要稳定的网络连接访问 API 服务
- 如遇连接问题，请检查网络和防火墙设置

### 4. 响应时间

- API 调用通常在几秒内返回结果
- 响应时间取决于网络状况和 API 服务负载

## 故障排查

### 问题 1：启动时提示配置文件不存在

```
FileNotFoundError: 配置文件不存在: config.json
```

**解决方案**：
```bash
cp config.example.json config.json
```
然后编辑 `config.json` 填入您的 API Key。

### 问题 2：API 调用失败

```
API 调用失败: Invalid API Key
```

**可能原因和解决方案**：
1. API Key 填写错误 → 检查 `config.json` 中的 `api_key` 是否正确
2. API Key 未激活 → 在对应平台确认 API Key 状态
3. 账户余额不足 → 充值账户
4. API Key 权限不足 → 确认 API Key 具有调用权限

### 问题 3：网络连接超时

```
API 调用失败: Connection timeout
```

**解决方案**：
1. 检查网络连接是否正常
2. 确认能访问对应的 API 服务地址
3. 检查防火墙设置
4. 如在国内，确认 API 服务在国内可用

### 问题 4：前端无法连接后端

**解决方案**：
1. 确认后端服务已启动（应该在 `http://localhost:5000`）
2. 检查浏览器控制台的错误信息
3. 确认没有端口冲突
