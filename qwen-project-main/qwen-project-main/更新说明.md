# 更新说明 - 从本地部署到API调用

## 📢 重要变更

本次更新将古文解析服务从**本地模型部署**改为**调用大模型API**，无需GPU和大型模型文件，使用更加便捷。

---

## 🆕 主要变化

### 1. **不再需要本地模型**
- ❌ 无需下载 1-2GB 的模型文件
- ❌ 无需 NVIDIA GPU 和 2GB+ 显存
- ✅ 只需配置 API Key 即可使用

### 2. **依赖大幅简化**
```diff
旧版本 requirements.txt:
- torch>=1.10.0,<3.0.0
- transformers>=4.25.0,<5.0.0
- protobuf>=3.20.0,<5.0.0
- numpy>=1.21.0
- accelerate>=0.20.0
- safetensors>=0.3.0

新版本 requirements.txt:
+ requests>=2.28.0
  flask>=2.0.0,<3.0.0
  flask-cors>=3.0.10
```

### 3. **支持多种大模型API**
- ✅ OpenAI (GPT-3.5/GPT-4)
- ✅ 阿里云通义千问
- ✅ 百度文心一言
- ✅ 智谱AI (ChatGLM)
- ✅ Anthropic Claude

### 4. **性能提升**
- ⚡ 启动速度：从 1-3分钟 → **1秒**
- ⚡ 响应速度：从 几分钟 → **3-10秒**
- 🎯 效果质量：Qwen3-0.6B → **GPT-3.5/4 级别**

## 🔄 迁移步骤

### 步骤1：更新依赖

```bash
cd qwen-project-main
pip uninstall torch transformers  # 可选：卸载旧依赖
pip install -r requirements.txt   # 安装新依赖
```

### 步骤2：配置API密钥 ⚠️

打开 `qwen.py`，在文件顶部找到配置区域：

```python
# ============ 配置区域 ============
# 请在这里填写您的API配置

API_TYPE = "openai"  # 选择API类型
API_KEY = "YOUR_API_KEY_HERE"  # ⚠️ 必填：填写您的API密钥
API_BASE_URL = "https://api.openai.com/v1"
MODEL_NAME = "gpt-3.5-turbo"
```

**详细配置方法请参考：[API配置示例.md](API配置示例.md)**

### 步骤3：启动服务

```bash
python qwen.py
```

### 步骤4：测试

```bash
curl -X POST http://localhost:5000/api/analyze \
  -H "Content-Type: application/json" \
  -d '{"text":"学而时习之，不亦说乎"}'
```

## 💰 费用对比

### 旧版本（本地部署）
- 💻 硬件成本：需要支持CUDA的显卡（约¥2000+）
- ⚡ 电费：运行时功耗约100-200W
- 🆓 使用成本：免费（忽略电费）
- 🐢 速度：较慢

### 新版本（API调用）
- 💻 硬件成本：普通电脑即可
- ⚡ 电费：可忽略
- 💵 使用成本：按调用次数/Token计费
  - GPT-3.5: 约 ¥0.01-0.03/次
  - 通义千问: 约 ¥0.01/次
  - 文心一言: 有免费额度
- ⚡ 速度：快速

### 建议
- **个人学习/小规模使用**：API版本更划算（免去硬件成本）
- **大规模商用/离线环境**：考虑本地部署
- **有免费额度的服务**：可以免费使用（文心一言、智谱AI）

## ❓ 常见问题

### Q: 我必须使用API吗？能否继续用本地模型？
A: 可以回退到旧版本使用本地模型，但新版本功能更强大、使用更便捷。

### Q: 哪个API最好？
A: 
- 国际用户 → OpenAI GPT-3.5/4
- 国内用户 → 阿里云通义千问
- 免费试用 → 百度文心一言或智谱AI

### Q: API会不会很贵？
A: 对于个人使用，成本很低：
- 每次解析约 ¥0.01-0.03
- 每天使用10次，月成本约 ¥3-10

### Q: 我的API Key会不会泄露？
A: 
- API Key 只保存在本地 `qwen.py` 文件中
- 不要将代码上传到公开仓库
- 建议使用环境变量存储（参考配置示例）

### Q: 前端需要修改吗？
A: **完全不需要！** API接口保持不变，前端代码零修改。
